**新时代新概念相邻加成！ | A New Era of Adjacency Bonuses!**

本项目是《文明6》模块化相邻加成体系的核心框架，旨在为 Modder 提供无限的想象空间和自由组合相邻加成的能力。它不仅可以彻底取代原版的相邻加成系统，还引入了大量黑科技功能。

This project is the core framework for the "Modular Adjacency Bonus" (MAB) system in *Civilization VI*. It aims to provide modders with unlimited imaginative space and the ability to freely combine adjacency bonuses. It can completely replace the original adjacency system and introduces numerous advanced features.

---

## 🌟 项目简介 | Project Introduction

本项目原名为“全新相邻加成”，现已全面更新为**模块化相邻加成（核心版）**。它是正式版的前置 Mod，也是整个模块化相邻体系的基石。

Originally named "New Adjacency Bonus," this project has been fully updated to the **Modular Adjacency Bonus (Core)**. It serves as the prerequisite for the full version and is the cornerstone of the entire MAB ecosystem.

### 核心特性 | Core Features:
- **多样化的产出类型 | Diverse Yield Types**: 
  - 支持基本六产（粮、锤、金、科、文、信）及其百分比系数、旅游业绩、宜居度、忠诚度、外交支持点、区域位、伟人点等。
  - Supports the 6 basic yields (Food, Production, Gold, Science, Culture, Faith) plus percentage multipliers, Tourism, Amenities, Loyalty, Diplomatic Favor, District Slots, Great Person Points, and more.
- **多环相邻支持 (BFS) | Multi-ring Adjacency (BFS)**: 
  - 打破原版仅限相邻一环的限制。利用广度优先搜索算法（BFS），可以让更多环数内的地形、地貌、资源、改良、区域成为相邻来源。
  - Breaks the vanilla 1-ring limit. Using Breadth-First Search (BFS), it allows terrains, features, resources, improvements, and districts within multiple rings to serve as adjacency sources.
- **UI 深度优化 | Deep UI Optimization**:
  - 修复了后期开启城市面板极其卡顿的 Bug。 / Fixes the severe late-game lag when opening city panels.
  - 能够将区域的特殊产出直接显示在相邻加成 UI 上。 / Displays special district yields directly on the adjacency UI.
  - 即使不使用任何加成逻辑，也可作为 UI 优化插件单开。 / Can be used as a standalone UI optimization plugin without any bonus logic.
- **高度自由的组合 | Highly Flexible Combinations**: 
  - 为 Modder 提供了通过 SQL 简单配置即可实现复杂相邻逻辑的空间。
  - Provides modders with the space to implement complex adjacency logic through simple SQL configuration.

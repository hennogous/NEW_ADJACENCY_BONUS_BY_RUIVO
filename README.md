**新时代新概念相邻加成！**

本项目是《文明6》模块化相邻加成体系的核心框架，旨在为 Modder 提供无限的想象空间和自由组合相邻加成的能力。它不仅可以彻底取代原版的相邻加成系统，还引入了大量黑科技功能。

## 🌟 项目简介

本项目原名为“全新相邻加成”，现已全面更新为**模块化相邻加成（核心版）**。它是正式版的前置 Mod，也是整个模块化相邻体系的基石。

### 核心特性：
- **多样化的产出类型**：支持基本六产（粮、锤、金、科、文、信）及其百分比系数、旅游业绩、宜居度、忠诚度、外交支持点、区域位、伟人点等。
- **多环相邻支持 (BFS)**：打破原版仅限相邻一环的限制。利用广度优先搜索算法（BFS），可以让更多环数内的地形、地貌、资源、改良、区域成为相邻来源。
- **UI 深度优化**：
  - 修复了后期开启城市面板极其卡顿的 Bug。
  - 能够将区域的特殊产出直接显示在相邻加成 UI 上。
  - 即使不使用任何加成逻辑，也可作为 UI 优化插件单开。
- **高度自由的组合**：为 Modder 提供了通过 SQL 简单配置即可实现复杂相邻逻辑的空间。

- **和而不同 (VP)**：完美兼容（专为和而不同制作，但不开启亦可正常运行）。
- **互斥说明**：**不能**与旧版的“全新相邻加成”同时开启。
- **前置需求**：作为模块化相邻加成（正式版）的必要核心前置。

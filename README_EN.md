**A New Era of Adjacency Bonuses!**

This project is the core framework for the "Modular Adjacency Bonus" (MAB) system in *Civilization VI*. It aims to provide modders with unlimited imaginative space and the ability to freely combine adjacency bonuses. It can completely replace the original adjacency system and introduces numerous advanced features.

## 🌟 Project Introduction

Originally named "New Adjacency Bonus," this project has been fully updated to the **Modular Adjacency Bonus (Core)**. It serves as the prerequisite for the full version and is the cornerstone of the entire MAB ecosystem.

### Core Features:
- **Diverse Yield Types**: Supports the 6 basic yields (Food, Production, Gold, Science, Culture, Faith) plus percentage multipliers, Tourism, Amenities, Loyalty, Diplomatic Favor, District Slots, Great Person Points, and more.
- **Multi-ring Adjacency (BFS)**: Breaks the vanilla 1-ring limit. Using Breadth-First Search (BFS), it allows terrains, features, resources, improvements, and districts within multiple rings to serve as adjacency sources.
- **UI Deep Optimization**:
  - Fixes the severe late-game lag when opening city panels.
  - Displays special district yields directly on the adjacency UI.
  - Can be used as a standalone UI optimization plugin without any bonus logic.
- **Highly Flexible Combinations**: Provides modders with the space to implement complex adjacency logic through simple SQL configuration.

## 🛠 Compatibility

- **Vox Populi (VP)**: Fully compatible (specifically designed for VP, but works fine without it).
- **Conflicts**: **Cannot** be enabled alongside the old "New Adjacency Bonus" mod.
- **Prerequisites**: Required core prerequisite for the full version of Modular Adjacency Bonus.
